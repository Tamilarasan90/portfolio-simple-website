# Personal Portfolio Website

## 📌 About the Project

A simple and professional personal portfolio website developed using **HTML5 and CSS3**. This project includes two pages: a Portfolio page to showcase personal details, skills, and projects, and a Contact page to provide contact information.

The website demonstrates my front-end development skills, focusing on clean design, structured content, and CSS styling.

## ✨ Pages

- **Portfolio Page:** Presents my profile and showcases my skills and projects.
- **Contact Page:** Provides contact details and a way for visitors to connect with me.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Project Objective

To build a personal website that showcases my work and provides an online presence while strengthening my fundamentals in HTML and CSS.
